# Credit Card Default Analysis

## Overview
This independent project analyses a real-world dataset on credit card defaults to investigate patterns associated with financial risk. The project applies statistical and machine learning techniques to identify predictors of default and interpret insights for decision-making in a finance context.

## Tools & Libraries
- Python (Pandas, NumPy, Matplotlib, Seaborn, scikit-learn)
- Jupyter Notebooks

## Methods
1. **Data Cleaning & Exploration**
   - Handled missing and anomalous values
   - Explored demographic, financial, and repayment variables
   - Visualised distributions, relationships, and correlations

2. **Predictive Modelling**
   - Logistic Regression and Random Forest classifiers
   - Dataset balancing and hyperparameter tuning
   - Model evaluation using accuracy, precision, recall, and AUC
   - Feature importance analysis for interpretability

3. **Insights & Interpretation**
   - Combined quantitative results with contextual understanding of socioeconomic patterns
   - Highlighted variables with strongest influence on default likelihood

## Outcomes
- Demonstrated application of analytical and operational research principles
- Developed skills in data cleaning, statistical modelling, reproducibility, and data-driven decision-making
- Insights could inform financial risk assessment and lending strategies
